# influence-disclosure

Name reservation only. No API, and none is planned for v0.

The Influence Disclosure Section is an open, signed, machine-readable statement of the paid
relationships behind one AI recommendation. The specification and the reference
implementation live at <https://github.com/mnemox-ai/influence-disclosure>.

Validate a disclosure without installing anything:

```bash
npx influence-disclosure-cli validate ./disclosure.json
```

A Python SDK will be published under this name if and when one is built. Until then this
package intentionally does nothing.
